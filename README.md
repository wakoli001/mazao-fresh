# mazao-fresh
🌿 About the ProjectMazao Fresh Kenya is a youth-led agribusiness start-up based in 

Nakuru Town, Nakuru County. The platform connects smallholder farmers growing produce 

like tomatoes, kales (sukuma wiki), avocados, and maize directly to buyers in urban 

markets including Nairobi, Nakuru, and Eldoret. By cutting out exploitative brokers, 

the platform ensures fair prices for farmers while providing affordable, fresh produce 

to urban households and restaurants.   This repository contains the first version of 

the web application built using plain HTML and basic inline styling as part of an IT 

consulting and web technology evaluation project.   📁 Repository & Folder 

StructureAs per project specifications, the application is organized within a 

dedicated root folder:   

├── index.html        # Home Page

├── about.html        # About Us Page

├── produce.html      # Product Catalogue Page

└── contact.html      # Contact Us Page

📄 Page Overview & Requirementsindex.html (Home):

Features the business name, logo placeholder, a short tagline, a navigation menu 

linking to all pages, and a welcome introduction introducing Mazao Fresh Kenya.   

about.html (About Us): Details the company description, mission statement, and an 

ordered list of strategic business objectives.   produce.html (Our Produce): Displays 

an HTML table listing at least 6 produce items with columns for Produce, Category, 

Price (Ksh), and Availability, complete with product images.   contact.html (Contact 

Us): Includes a functional contact form (name, email, phone, message, submit button), 

physical address details, and an embedded Google Map iframe of Nakuru Town.   🛠️ 

Technical Requirements & StackLanguage: Plain HTML5   Styling: Basic inline CSS (no 

external frameworks used)   Semantic Elements: Built using modern semantic tags 

including <header>, <nav>, <main>, <section>, and <footer>.   Content Elements: 

Features at least one ordered list (<ol>), one unordered list (<ul>), one data table 

(<table>), and one interactive form (<form>).   Navigation: Fully linked multi-page 

structure with a working navigation bar across all views.   🚀 Planned Digital 

ServicesIn future iterations, the platform aims to scale by integrating advanced web 

technologies:Online Produce Catalogue: Real-time browsing for buyers.   M-Pesa 

Integration: Seamless mobile money payments for orders.   SMS Order Alerts: Automated 

notifications for farmers when orders are placed.   Weather API Updates: Live weather 

forecasts to help smallholder farmers plan harvesting cycles.
